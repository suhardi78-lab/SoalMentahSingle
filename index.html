📊 9. Integrasi Google Spreadsheet (Kirim Nilai Otomatis)

Masukkan URL Web App dari Google Apps Script untuk menerima hasil ujian siswa secara otomatis ke Google Spreadsheet.

💡 Panduan Pembuatan Google Apps Script:
  1. Buat Google Spreadsheet baru di Google Drive Anda.
  2. Klik menu Ekstensi > Apps Script.
  3. Hapus kode lama dan tempel kode berikut: 
    function doPost(e) {
  var lock = LockService.getScriptLock();
  try {
    lock.waitLock(10000); // Tunggu antrean maksimal 10 detik agar tidak ada bentrok antar HP
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);

    // Inisialisasi header kolom jika sheet masih kosong
    if (sheet.getLastRow() == 0) {
      sheet.appendRow(["Timestamp", "Nama", "Nomor Absen", "Kelas", "Nilai", "Benar", "Total Soal", "Pelanggaran", "Auto Submit", "Waktu Selesai", "ID Submission"]);
    }

    // Pencegahan Dobel Data (Idempotensi): Cek apakah submissionId sudah pernah tercatat
    var submissionId = String(data.submissionId || "");
    if (submissionId) {
      var lastRow = sheet.getLastRow();
      if (lastRow > 1) {
        var existingIds = sheet.getRange(2, 11, lastRow - 1, 1).getValues();
        for (var i = 0; i < existingIds.length; i++) {
          if (String(existingIds[i][0]) === submissionId) {
            return ContentService.createTextOutput(JSON.stringify({result: "already_exists", message: "Data sudah ada"})).setMimeType(ContentService.MimeType.JSON);
          }
        }
      }
    }

    sheet.appendRow([
      data.waktuSelesai || new Date(),
      data.nama || "",
      data.nomor || "",
      data.kelas || "",
      data.nilai || 0,
      data.benar || 0,
      data.totalSoal || 0,
      data.pelanggaran || 0,
      data.autoSubmit ? "Ya" : "Tidak",
      data.waktuSelesai || "",
      submissionId
    ]);
    SpreadsheetApp.flush();
    return ContentService.createTextOutput(JSON.stringify({result: "success"})).setMimeType(ContentService.MimeType.JSON);
  } catch(error) {
    return ContentService.createTextOutput(JSON.stringify({result: "error", error: error.toString()})).setMimeType(ContentService.MimeType.JSON);
  } finally {
    lock.releaseLock();
  }
}
  4. Klik Terapkan (Deploy) > Penerapan baru (New deployment).
  5. Pilih jenis: Aplikasi web (Web app).
  6. Setel "Siapa yang memiliki akses" (Who has access) ke: Siapa saja (Anyone).
  7. Klik Terapkan (Deploy), lalu berikan izin akses:
    • Jika muncul peringatan "Google hasn't verified this app", klik Advanced (Tingkat lanjut) di kiri bawah.
    • Klik Go to ... (unsafe) / Lanjutkan ke ... (tidak aman).
    • Klik Allow / Izinkan.
    • (Peringatan ini normal karena skrip dibuat sendiri dan belum didaftarkan sebagai aplikasi publik oleh Google).
  8. Salin URL Aplikasi Web (Web App URL) lalu tempel pada kolom di atas.

🐙 10. Integrasi GitHub Auto-Sync (Update Langsung di Web GitHub)

Atur token dan repositori GitHub agar setiap perubahan data/pengaturan langsung ter-commit dan ter-update di website GitHub Pages tanpa harus download HTML.

NONAKTIF
💡 Panduan Membuat Personal Access Token (PAT) GitHub:
  1. Login ke akun GitHub Anda, lalu buka Settings > Developer Settings > Personal access tokens > Tokens (classic) (atau Fine-grained tokens).
  2. Klik Generate new token.
  3. Beri nama/note (misal: Aplikasi Evaluasi PKK) dan set masa berlaku (Expiration).
  4. Centang centang izin repo (untuk Classic Token) atau berikan izin Contents: Read and write (untuk Fine-grained token).
  5. Klik Generate token, salin kode token tersebut (awalan ghp_ / github_pat_) dan tempel pada kolom di atas.
